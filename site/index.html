Nothing on screen you didn't ask for.

An IDE gives every panel to everyone. You direct agents, so Minga shows only your text until an agent needs you, then builds the one view your task needs.

One line tells you who needs you.

Run three agents and you cannot watch all of them. The status line at the bottom of the window counts the tasks that wait for your answer, in words. Every task shows one of six states as a shape and a word, so you never decode an icon.

  • Working
  • Needs you
  • Waiting
  • Stopped
  • Failed
  • Done

Make it yours in five lines.

Minga reads your settings from ~/.config/minga/config.exs, written in the Elixir language: these lines set the theme, the line numbers and the tab width, and format Go files when you save them. See what else you can change.

~/.config/minga/config.exs Elixir 
use Minga.Config

set :theme, :catppuccin_mocha
set :line_numbers, :relative
set :tab_width, 4
for_filetype :go, format_on_save: true

Keep typing while your agents work.

A slow language server or a busy agent does not freeze your typing, and Architecture shows why, and where that promise stops.

Minga is a pre-release, and other tools do things it does not. Read when to switch, and when to stay.
