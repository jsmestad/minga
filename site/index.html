A programmable workbench where text is the interface.

Code editing, parallel agents, and Elixir workflows in one keyboard-first workbench shared by macOS and the terminal. Built on the Erlang VM so every open file, language server, extension, and agent runs isolated, while agent edits stage off your working tree with syntax-highlighted diff review until you publish.

01 Visual Grammar

Two visual marks. Five semantic roles.

No icon rail, tab strip, or permanent sidebar. Every color maps to a semantic role (minga, you, needs_you, failure, done) in your theme, defaulting to Catppuccin Frappé.

The Twist: authorship in the gutter

Replaces a separate git sign column; the crossing pins to the top as you scroll.

  • Minga unreviewed Braided minga strands; SPC a y keep, SPC a d reject
  • Shared edit One strand turns you on lines you edited inside Minga's change
  • Your lines Single you strand; u undoes only your edits
  • Accepted Muted single strand until commit

The Orbit: live state everywhere

Six state words on five shapes across modeline, drawers, and notifications. Only needs_you escalates.

  • Working Visible only while running TUI: ◐
  • Needs you Escalates without stealing focus TUI: ◉
  • Waiting / Stopped Hollow dot with reason and retry timer TUI: ○
  • Failed Diamond with cause and next step TUI: ◆
  • Done Ready inline or in *minga-review* TUI: ●

Vim stays Vim inside code.

y always yanks and n steps search. Review via SPC a y/SPC a d, ih/ah, or *minga-review*.

One drawer at a time.

Drawers close with q/esc and yield before code drops below 100 columns; auto-opened approvals lock y for 300 ms.

03 Programmability

From five lines in config.exs to task-shaped Elixir workflows.

Zero config required to start. When you customize Minga, one Elixir runtime scales from live-reloaded options to supervised packages.

  • Live config (SPC h r)

    Typed options, keybindings, async save hooks, and command wrappers in ~/.config/minga/config.exs.

  • Supervised packages (minga_sdk)

    Install from Hex, Git, or local paths, override load_policy without forking, or plug in a corporate InferenceRoute proxy.

  • Task workflows (v0.1.0)

    Author a review or check surface over buffers and agents, activate under a revocable grant, then discard or reuse across repos.

Explore all three layers and security boundaries on Extending Minga ->

~/.config/minga/config.exs Elixir · Reload via SPC h r 
use Minga.Config

set :theme, :catppuccin_frappe
set :line_numbers, :relative
set :tab_width, 2

bind :normal, "SPC m t", :run_tests, "Run project tests"
command :run_tests, "Run test suite" do
  {out, _} = System.cmd("mix", ["test"])
  Minga.API.message(out)
end

extension :minga_git_extended,
  hex: "minga_git_extended", version: "~> 0.1"

04 Runtime

Erlang VM isolation behind native code.

Buffers, language servers, extensions, MCP servers, and agents run in separate processes with separate heaps; Swift, Go, and Zig handle pixels and parsing.

No UI freezes

Preemptive scheduling and per-process GC keep typing smooth while agents stream and hooks run.

Isolated MCP & plugins

If an extension or stdio MCP server crashes mid-turn, only its tools drop out (MCP).

Staged & gated tools

Revision-checked overlays, write-ahead logs, and local PreToolUse shell vetoes (Hooks).

Headless devboxes

Run minga --headless under systemd/launchd and attach over SSH without copying source (Remote).
