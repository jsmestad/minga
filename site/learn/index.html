LEARN Five-Lesson Curriculum

Learn Minga

Go from zero-config install to keyboard-first editing, parallel agent co-authoring, Elixir customization, and persistent remote devboxes. Each guide includes concrete examples and interactive drills you can try right in the browser.

1. Five-lesson path 2. Interactive drills 3. Deep references

1. The learning path

Lesson 01 teaches today's rolling Homebrew prerelease build so you can install Minga and run your first staged edit right away. Lessons 02 and 03 teach the v0.1.0 Spine design directly (marked Coming · v0.1.0 until the full surface set lands). Lessons 04 and 05 cover Elixir customization, hooks, MCP, and headless remote sessions that ship on main today.

  1. LESSON 01 Ships today

    Install & Your First Staged Edit

    Install signed Apple Silicon macOS desktop or terminal builds via Homebrew (or build from source on Linux and Intel Macs), choose Vim modal or desktop shortcuts, connect a model provider, review your first syntax-highlighted staged diff, and drop four starter recipes into config.exs.

    Homebrew & source Model keys & /model Staged diff review 4 starter recipes
  2. LESSON 02

    Editing, Keys & Quiet Chrome

    Learn the v0.1.0 resting screen (plain title bar, your text, one prioritized modeline), mnemonic SPC leader sequences, Doom-first navigation, pinned files, bottom drawers, two-level Hover (K), the decision-first Act Menu (g. / ⌃.), first-class mouse paths, and the CUA key profile (ADR-0007).

    SPC grammar Drawers & switcher Act Menu & mouse CUA profile Interactive drill
  3. LESSON 03

    Co-Authoring & Parallel Agents

    Read the Twist authorship gutter and the Orbit's six states on five shapes, use per-author undo (u / ⌘Z), review changes inline or in *minga-review*, approve requests in *minga-tasks* without focus theft, inspect workers in Subagent Peek (SPC a i), and steer or queue follow-ups in *minga-queue*.

    The Twist & Orbit Per-author undo *minga-review* Subagent Peek Interactive lab
  4. LESSON 04 Ships today

    Elixir for Minga (Zero Prior Elixir Needed)

    A fast, practical translation guide from Lua (Neovim), Elisp (Emacs), and TypeScript/JSON (VS Code) to the tiny subset of Elixir you need for ~/.config/minga/config.exs: atoms, keyword lists, anonymous functions, save hooks, command advice, and growing into supervised minga_sdk packages.

    Lua / Elisp / JS map config.exs DSL Hooks & advise Interactive builder
  5. LESSON 05 Ships today

    Remote Devboxes, MCP & Safety Guardrails

    Keep agents running across laptop sleep with minga --headless and minga attach ssh://, gate shell tools with deterministic PreToolUse veto scripts, attach crash-isolated stdio MCP servers, and route corporate traffic through MingaAgent.InferenceRoute.

    minga --headless PreToolUse hooks Isolated MCP Corporate gateways
