01 Headless

Keep agents working across laptop sleep on your devbox.

In headless mode, the server runs only buffer, project, and agent services (no editor, renderer, or parser OS processes). When you run minga attach, your local client renders the UI and subscribes over Erlang distribution with a shared RELEASE_COOKIE (Remote Agents).

Remote devbox + local attach 
# 1. On your Linux devbox (keep user services alive after logout):
loginctl enable-linger "$USER"
minga --headless

# 2. From your Mac or another terminal (zero source code copied locally):
minga attach ssh://devbox/work/app

02 Guardrails

Deterministic PreToolUse shell veto hooks.

Prompts suggest; shell exit codes enforce. Non-zero exit blocks the tool and surfaces stderr in chat (Hooks). Reload live with SPC h r.

~/.config/minga/config.exs · Hook registration 
set :agent_hooks, [
  %{
    event: "PreToolUse",
    tool: "shell",
    command: "~/.config/minga/hooks/check-shell-command.sh",
    timeout_ms: 10_000
  }
]
~/.config/minga/hooks/check-shell-command.sh 
#!/usr/bin/env bash
set -euo pipefail

cmd=$(jq -r '.arguments.command // ""')

if [[ "$cmd" == *"git push --force"* || "$cmd" == *"rm -rf /"* ]]; then
  echo "Blocked by local safety hook: destructive command not allowed." >&2
  exit 1
fi

03 MCP & Gateways

Crash-isolated stdio MCP servers.

Each stdio MCP server runs isolated with prefixed tools (mcp_<server>__<tool>) and destructive approval by default (MCP). Read secrets from env vars so tokens never enter dotfiles.

~/.config/minga/config.exs · Multiple stdio MCP servers 
set :agent_mcp_servers, [
  %{
    name: "github",
    command: "npx",
    args: ["-y", "@modelcontextprotocol/server-github"],
    env: %{"GITHUB_PERSONAL_ACCESS_TOKEN" => System.fetch_env!("GITHUB_TOKEN")}
  },
  %{
    name: "postgres",
    command: "npx",
    args: ["-y", "@modelcontextprotocol/server-postgres", System.fetch_env!("DATABASE_URL")]
  }
]

For corporate LLM proxies (MingaAgent.InferenceRoute) and credential boundaries, see Extending Minga; for terminal protocol support over SSH, see Architecture.
