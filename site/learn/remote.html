01 Headless

Keep agents working across laptop sleep on your devbox.

In headless mode, the Erlang VM boots only buffer, project, and agent services; the editor renderer and syntax parser OS processes start only when a client attaches. Full systemd and launchd units live in the Remote Agents Reference.

Remote devbox + local attach 
# 1. On your Linux devbox (keep user services alive after logout):
loginctl enable-linger "$USER"
minga --headless

# 2. From your Mac or another terminal (zero source code copied locally):
minga attach ssh://devbox/work/app

02 Guardrails

Deterministic PreToolUse shell veto hooks.

Prompt instructions are advice; shell exit codes are enforcement. Minga pipes JSON call arguments on stdin, enforces a POSIX process-group timeout, blocks on any non-zero exit, and surfaces stderr directly in chat (Hooks Reference). Reload live with SPC h r.

~/.config/minga/config.exs · Hook registration 
set :agent_hooks, [
  %{
    event: "PreToolUse",
    tool: "shell",
    command: "~/.config/minga/hooks/check-shell-command.sh",
    timeout_ms: 10_000
  }
]
~/.config/minga/hooks/check-shell-command.sh 
#!/usr/bin/env bash
set -euo pipefail

cmd=$(jq -r '.command // ""')

if [[ "$cmd" == *"git push --force"* || "$cmd" == *"rm -rf /"* ]]; then
  echo "Blocked by local safety hook: destructive command not allowed." >&2
  exit 1
fi

03 MCP & Gateways

Crash-isolated stdio MCP servers and corporate LLM routes.

Each stdio MCP server runs in its own supervised process with prefixed tools (mcp_<server>__<tool>) and destructive approval by default (MCP Reference). Read secrets from environment variables so tokens never enter dotfiles.

~/.config/minga/config.exs · Multiple stdio MCP servers 
set :agent_mcp_servers, [
  %{
    name: "github",
    command: "npx",
    args: ["-y", "@modelcontextprotocol/server-github"],
    env: %{"GITHUB_PERSONAL_ACCESS_TOKEN" => System.fetch_env!("GITHUB_TOKEN")}
  },
  %{
    name: "postgres",
    command: "npx",
    args: ["-y", "@modelcontextprotocol/server-postgres", System.fetch_env!("DATABASE_URL")]
  }
]

Corporate gateways & local credentials

Implement MingaAgent.InferenceRoute to stream through an internal proxy while Minga keeps owning staged overlays, approvals, compaction, and crash-safe logs (Model Routes Reference). Zero telemetry is sent; keys saved via /auth live locally in 0600 credentials.json.
