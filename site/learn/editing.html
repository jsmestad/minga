Editing, Keys & Quiet Chrome

Minga's v0.1.0 interface model (ADR-0006) strips the resting window down to a plain title bar, your text, and one modeline. Every panel opens on demand as a real buffer, every key follows a strict mnemonic grammar, and every click teaches its key.

v0.1.0 Spine design guide

This lesson teaches the canonical v0.1.0 Spine interface from ADR-0006 and docs/design/keys.md. For commands matching today's rolling Homebrew prerelease build, start with Lesson 01: Getting Started.

1. The resting screen (and why tabs are gone)

Open a project with minga . and look at what is missing: no icon rail, no permanent sidebar, no tab bar across the top, and no separate agent workspace. At rest, Minga gives 100% of the window to three elements: a plain title bar naming the focused file and its project-relative directory, your text buffer, and one prioritized modeline along the bottom.

When you open a project you worked in before, Minga restores your open files, splits, cursors, and scroll position automatically (press SPC q n to start fresh at the project home *home* without discarding unsaved edits or Minga's unreviewed changes). On a fresh directory, *home* opens with numbered recent files, active tasks, and next actions; SPC p h brings it back anytime.

Navigating without a tab strip

Instead of hunting through 18 truncated tabs, Minga pairs an instant switcher with four pinned slots and Vim's jump list:

  • SPC , / SPC b b Open the file and buffer switcher. Sections show Pinned, Changed (your unsaved files alongside Minga's tasks), Recent, and Terminals. Use ⌃J / ⌃K to move, ⌃V to open in a split, and ⌃T to pin or unpin.
  • SPC 1 to SPC 4 Jump directly to pinned files 1 through 4 (⌘1 to ⌘4 on macOS).
  • SPC SPC / SPC s p Find any file or search across the project. In project search, pass ripgrep flags after -- (for example retry -- -uu); if nothing matches, next-step rows offer ignored or hidden files directly, and ⌃Q sends results to quickfix (SPC s q).
  • ⌃O / ⌃I Step back and forward through your jump list (⌘[ / ⌘] on macOS, or trackpad swipe).
  • SPC c d / SPC c D Go to definition or find references. Expand and shrink syntax-node selection with SPC c v / SPC c V.
  • SPC c x / SPC g g Open diagnostics list or git status. Step diagnostics with ]e / [e, step git hunks with ]d / [d, and toggle inline blame with SPC g B.

2. The key grammar: chords you can say out loud

Every keybinding in Minga obeys one strict precedence order (Doom Emacs conventions first, Neovim second). Once you learn the five rules, you can guess bindings you have never seen before:

  1. 01

    Mnemonic leader sequences first (SPC)

    Press SPC and pause to open which-key above the modeline. Top-level groups map to single mnemonic letters: a Minga, b buffers, c code, f files, g git, h help, o open, p project, q quit and session, s search, t toggles, and w windows. Groups appear in Title Case with a trailing › and live counts (for example Session › 7 or Tasks · 1 needs you).

  2. 02

    Vim stays Vim inside code buffers

    Inside a source file, y always yanks, n always steps search, = always formats, and q always records macros. Operators, motions, counts, . repeat, and bracket pairs (]h/[h Minga changes, ]e/[e diagnostics, ]d/[d git hunks, ]q/[q quickfix) compose normally.

  3. 03

    Bare mnemonic letters live only in special buffers

    In buffers where letters do not insert text (*minga-tasks*, *minga-review*, git status, file tree, blame), single letters act immediately: y yes/keep, n no/reject, r retry, o output, q close.

  4. 04

    Modifiers only where letters must type text

    Inside prompts, pickers, Insert mode, and the composer, typing always edits text. Only established conventions use modifiers: ⌃J / ⌃K move in lists, ⌃V / ⌃T / ⌃Q act in pickers, ⌥↩ queues a follow-up in the composer, ⌃\ ⌃N leaves terminal mode, and ⌃. opens the Act Menu.

  5. 05

    macOS keys as aliases; zero three-modifier chords

    macOS shortcuts (⌘S, ⌘Z, ⌘W, ⌘., ⌘K, ⌘1 to ⌘4) mirror leader bindings that work identically in the terminal. Minga never binds three-modifier chords, Control+Command or Option+Command combinations, or function keys.

3. Drawers, Hover, and the decision-first Act Menu

Nothing traps you in a mystery mode. One rule closes everything across both macOS and the terminal: q closes special buffers and splits (returning focus to the window you came from), and esc cancels or dismisses anything transient (prompts, pickers, menus, overlays).

  • One drawer at a time Lists open in a bottom drawer split, never hiding your code. Opening another drawer replaces the current one; closing it restores the previous drawer. Panels yield before code does so your editor keeps at least 100 columns.
  • K then K Two-level Hover for anything under the cursor. The first K peeks at diagnostics, type signature, docs, or Minga attribution (ordered most urgent first). Press K again to focus the popover, scroll with j/k, copy with y, or close with q/esc.
  • g. / ⌃. / Right-click The Act Menu answers "what can I do with this?" On a yes/no target (like a Minga change or pending approval), the top bar splits into two halves with written consequences (y Keep / n Reject). Below sit quieter grouped actions showing the in-menu letter on the left and the direct key on the right so the menu teaches you to skip it next time.
  • SPC o t / SPC s u Built-in terminal drawer and edit timeline. SPC o t toggles the terminal drawer (step command blocks with ]] / [[ and select output with ic / ac), while SPC s u opens the edit timeline across both your edits and Minga's steps.

4. First-class mouse paths & the CUA key profile

Minga is keyboard-first, not keyboard-only. Every screen is reachable and dismissable by mouse, and every click teaches its shortcut:

  • The mode pill is the front door: clicking the NORMAL pill in the modeline opens top-level which-key, where every group and leaf is clickable. On macOS, the native menu bar mirrors the exact same SPC groups.
  • Every modeline segment is clickable: needs_you opens tasks, the file name opens the switcher, change 1/2 jumps to the change, diagnostics open the list, and git opens status.
  • Right-click opens the Act Menu (the same menu as g. and ⌃.), and prompts draw clickable answer chips (y, n, esc). Holding ⌘ on macOS reveals shortcuts on visible controls.

Prefer standard desktop shortcuts? (ADR-0007)

Set set :editing_model, :cua in ~/.config/minga/config.exs. Under ADR-0007, CUA is a first-class key profile rather than an afterthought: standard clipboard, undo, and palette bindings (Cmd+C/V/X/Z/Shift+Z/A on macOS; Ctrl+C/V/X/Z/Y/A and Ctrl+P / Ctrl+Shift+P in the terminal; ⌃J / ⌥↩ for composer newlines) are explicitly honored while one-meaning-per-key, live prompt movement (⌃J / ⌃K), and SPC leader sequences remain intact.
