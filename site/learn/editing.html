01 Grammar

Chords you can say out loud, Doom first.

Every binding follows five rules in strict order. Learn the rules once and you can predict keys you have never used before. For today's rolling Homebrew build keys, see Lesson 01.

1. Mnemonic leader sequences (SPC)

Discoverable

Pause after SPC to open which-key above the modeline: a Minga, b buffers, c code, f files, g git, h help, o open, p project, q quit, s search, t toggles, w windows. Groups show Title Case with a trailing › and live counts (Session › 7, Tasks · 1 needs you).

2. Vim inside code; bare letters in drawers

Context, not toggles

Inside a file, y always yanks, n always steps search, = formats, and q records macros. Bare single letters (y keep, n reject, r retry, o output, q close) live strictly in special buffers like *minga-tasks* and *minga-review*.

3. Navigate without a tab bar

Switcher + Pins

Open the Switcher (SPC , / SPC b b) for Pinned, Changed, Recent, and Terminals. Pin up to four files with ⌃T and jump directly with SPC 1 to SPC 4 (⌘1 to ⌘4). Step back and forward with ⌃O / ⌃I (⌘[ / ⌘]), or return to *home* with SPC p h (and start fresh with SPC q n).

4. Established modifiers only

Zero 3-mod chords

In live prompts (SPC SPC, SPC s p), typing always edits the query; move with ⌃J/⌃K, open split with ⌃V, send to quickfix with ⌃Q, queue follow-ups with ⌥↩, leave terminal mode with ⌃\ ⌃N, and open the Act Menu with ⌃.. macOS keys (⌘S, ⌘Z, ⌘W, ⌘., ⌘K) alias leader chords; Minga never binds Control+Command, Option+Command, or function keys.

02 Surfaces

One drawer at a time, two-level Hover, and the Act Menu.

Nothing traps you: q closes special buffers and splits, and esc cancels anything transient. Panels yield before code does so your editor keeps at least 100 columns.

  • g. / ⌃. / Right-click The Direction A Act Menu leads with the decision. On yes/no targets (a Minga change or approval), the top bar splits into y Keep and n Reject with written consequences. Grouped actions below list the in-menu letter on the left and the direct key on the right so the menu teaches you to skip it.
  • K then K Two-level Hover for anything under the cursor. First K peeks (ordered: diagnostic, signature, docs, attribution); second K focuses it so j/k scroll and y copies.
  • SPC c d / SPC c D Go to definition or find references. Expand and shrink syntax-node selection with SPC c v / SPC c V.
  • SPC c x / SPC g g Diagnostics list and git status. Step diagnostics with ]e / [e, git hunks with ]d / [d, inline blame with SPC g B, quickfix with SPC s q (]q/[q), terminal drawer with SPC o t (]]/[[, ic/ac), and edit timeline with SPC s u.

03 Mouse & CUA

First-class mouse paths and the ADR-0007 CUA key profile.

Every screen is reachable and dismissable by mouse, and every click teaches its key. Prefer desktop shortcuts over Vim? Set set :editing_model, :cua.

Mouse paths

Every click teaches a key
  • Click the NORMAL mode pill to open top-level which-key (mirrored in the macOS menu bar).
  • Click any modeline segment (needs-you, file name, change count, diagnostics, git) to jump straight there.
  • Right-click anywhere for the Act Menu; hold ⌘ on macOS to reveal shortcuts on visible controls.

CUA Key Profile (ADR-0007)

Desktop conventions

Under ADR-0007, :cua is an explicit key profile honoring standard desktop clipboard, undo, and palette bindings (Cmd+C/V/X/Z/Shift+Z/A on macOS; Ctrl+C/V/X/Z/Y/A and Ctrl+P / Ctrl+Shift+P in the terminal; ⌃J / ⌥↩ composer newlines) while keeping one-meaning-per-key, live prompt movement, and SPC leader sequences available.
