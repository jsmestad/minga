01 Grammar

Chords you can say out loud, Doom first.

Four rules govern every binding so you can predict shortcuts without memorizing them. For current prerelease keys, see Lesson 01.

1. Mnemonic leader (SPC)

Discoverable

Pause after SPC for which-key: a Minga, b buffers, c code, f files, g git, s search, w windows. Groups use trailing › with live counts (Tasks · 1 needs you).

2. Vim inside code; bare keys in drawers

Context, not toggles

Inside files, y yanks, n steps search, = formats, and q records macros. Bare single letters (y, n, q) live strictly in special buffers like *minga-tasks* and *minga-review*.

3. Navigate without tabs

Switcher + Pins

Open Switcher (SPC ,) for Pinned, Changed, and Recent files. Pin up to four with ⌃T, jump with SPC 1–4 (⌘1–4), and step history with ⌃O / ⌃I.

4. Established modifiers only

Predictable chords

In live prompts (SPC SPC, SPC s p), typing always edits the query; move with ⌃J/⌃K, open split with ⌃V, and open the Act Menu with ⌃.. macOS keys (⌘S, ⌘Z, ⌘W) alias leader chords.

02 Surfaces

One drawer at a time, two-level Hover, and the Act Menu.

q closes special buffers and splits; esc cancels anything transient. Panels yield before code drops below 100 columns.

  • g. / ⌃. / Right-click The Act Menu leads with the decision. On yes/no targets, the top bar splits into y Keep and n Reject with consequences; actions below show direct keys on the right so you outgrow the menu.
  • K then K Two-level Hover. First K peeks (diagnostic, signature, docs, attribution); second K focuses it to scroll or copy.
  • SPC c d / SPC c D Definition & references. Expand/shrink syntax selection with SPC c v / SPC c V.
  • SPC c x / SPC g g Diagnostics, git & quickfix. Step diagnostics (]e/[e), git hunks (]d/[d), inline blame (SPC g B), quickfix (SPC s q), and edit timeline (SPC s u). See Keymap Reference.

03 Mouse & CUA

First-class mouse paths and desktop shortcuts (:cua).

Every screen works by mouse, and every click teaches its key. Prefer desktop shortcuts? Add set :editing_model, :cua.

Mouse paths

Every click teaches a key
  • Click the NORMAL pill for top-level which-key (mirrored in the macOS menu bar).
  • Click any modeline segment (needs-you, file, changes, diagnostics, git) to jump straight there.
  • Right-click anywhere for the Act Menu; hold ⌘ on macOS to reveal shortcuts on visible controls.

Desktop shortcuts (CUA)

ADR-0007

:cua (ADR-0007) binds standard desktop clipboard, undo, save, and palette shortcuts (Cmd+C/V/X/Z/Shift+Z/S on macOS; Ctrl+C/V/X/Z/Y/S and Ctrl+P / Ctrl+Shift+P in the terminal) over the same minimal buffer layout.
