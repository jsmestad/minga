Learn / Lesson 02 of 05 · Find any command

Forgot the key? Press SPC.

Your spec is open and you want a different file. You know Minga can switch files, but you cannot remember the key. You do not have to memorise shortcuts: press SPC (the space bar), and Minga lists every key you can press next, with a name beside each one. Try it in the file below. It takes four steps.

01 What you saw

Two rules cover the rest of the keyboard.

You opened a file without knowing its key. The same two rules get you to every other command.

  • The SPC menu shows what comes next. Every Minga command starts with SPC, then a group letter, then an action letter. You only have to remember SPC: the menu names the rest, one level at a time. The menu is called which-key, after the Emacs and Neovim tool that does the same job.
  • Inside a file, Vim keys keep their Vim meaning. j moves down, w jumps a word, i lets you type, u undoes and q records a macro. Minga never takes a letter away from Vim inside your text, which is why its own commands start with SPC.

Backing out is as simple: esc closes any menu, list or prompt you opened. In Minga's own read-only views, such as the task list, letters are not text, so q closes the view there.

The rest of the keys are in the v0.1.0 key plan. It is the plan for v0.1.0, not the keys of today's build. If you prefer desktop shortcuts to Vim keys, add set :editing_model, :cua to your config file; that option is in today's build, and Configuration shows where the line goes.

What you can do differently: stop keeping a list of shortcuts. When you want a command, press SPC and read. The keys you use every day will stick on their own, and then you type them straight through and the menu never appears.
