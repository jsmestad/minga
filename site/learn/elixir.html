    System.cmd("gofmt", ["-w", path])
  end
end

  version: "~> 0.1",
  load_policy: {:on_command, [:git_log]}

02 Primitives

Six building blocks cover 95% of everyday customization.

Press SPC f p to open ~/.config/minga/config.exs, edit it, and press SPC h r to reload options, keybindings, hooks, and command wrappers live. Parentheses on calls are optional and the last expression in a block is its return value.

  • set Typed editor options. Minga's default theme is Catppuccin Frappé (:catppuccin_frappe); invalid option names or types report a clear notice instead of failing silently.
  • for_filetype Per-language option overrides. Pass the filetype atom and keyword pairs: for_filetype :go, tab_width: 4, indent_with: :tabs.
  • bind & command Custom commands and keybindings. Define an Elixir block with command :name, "Description" do ... end and bind it in a scope with bind :normal, "SPC m t", :name, "Description".
  • on & advise Isolated hooks and Emacs-style advice. Lifecycle hooks (on :after_save) run asynchronously in separate Erlang VM processes; advise wraps any built-in command (:before, :after, :around, :override) with contained exceptions.
  • extension Supervised packages from Hex, Git, or local paths. Override any extension's load_policy (:eager, :deferred, or {:on_command, [...]}) without forking it.

Graduating to minga_sdk

Move into a packaged extension when you need an OTP supervision tree, custom buffer surfaces, an internal MingaAgent.InferenceRoute proxy, runtime tree-sitter grammars, or Hex/Git distribution. Compiled package updates activate cleanly on restart (ADR-0003).

Disposable & reusable task workflows

In v0.1.0, author readable Elixir workflows over real buffer and agent owners for a single migration or audit, inspect the diff, save to activate under an explicit revocable grant, and discard when the PR lands or keep across repos. See Extending Minga.
