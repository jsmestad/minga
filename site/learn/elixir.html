use Minga.Config

set :theme, :catppuccin_frappe
set :line_numbers, :relative
set :tab_width, 2

for_filetype :go, tab_width: 4, indent_with: :tabs

on :after_save, fn _buf, path ->
  if String.ends_with?(path, ".go") do
    System.cmd("gofmt", ["-w", path])
  end
end

extension :minga_git_extended,
  hex: "minga_git_extended",
  version: "~> 0.1",
  load_policy: {:on_command, [:git_log]}

02 Primitives

Five building blocks cover 95% of everyday customization.

Press SPC f p to open ~/.config/minga/config.exs and SPC h r to reload options, keybindings, hooks, and command wrappers live.

  • set Typed editor options. Default theme is Catppuccin Frappé (:catppuccin_frappe); invalid names or types report a clear notice.
  • for_filetype Per-language overrides via keyword pairs (tab width, indentation, formatters).
  • bind & command Custom commands and keybindings scoped to any mode or filetype.
  • on & advise Isolated hooks and Emacs-style advice (:before, :after, :around, :override) with contained exceptions.
  • extension Supervised Hex, Git, or local packages with configurable load_policy.
