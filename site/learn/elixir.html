Elixir for Minga

You do not need to write Elixir at work to configure Minga. Just as Lua configures Neovim and Elisp configures Emacs, a tiny, readable subset of Elixir powers ~/.config/minga/config.exs, save hooks, command wrappers, and extensions.

1. Five-minute translation from Lua, Elisp, and JS

Every Minga configuration file uses the same six Elixir syntax shapes. If you have ever edited init.lua, init.el, or settings.json, you already recognize every concept below:

Scroll table horizontally ->
Concept Elixir in Minga Lua (Neovim) Elisp (Emacs) JS / JSON (VS Code)
Named tag (Atom) :catppuccin_frappe, :normal "catppuccin_frappe" 'catppuccin-frappe "catppuccin_frappe"
Options (Keyword list) tab_width: 4, indent_with: :tabs { tab_width = 4, indent = "tabs" } (:tab-width 4 :indent 'tabs) { tabWidth: 4, indent: "tabs" }
Object / Map %{event: "PreToolUse", tool: "shell"} { event = "PreToolUse", tool = "shell" } '((event . "PreToolUse")) { event: "PreToolUse", tool: "shell" }
Fixed tuple {:on_command, [:git_log]} { "on_command", { "git_log" } } '(on-command (git-log)) ["on_command", ["git_log"]]
Anonymous function fn _buf, path -> ... end function(_, path) ... end (lambda (_buf path) ...) (_buf, path) => { ... }
Unused variable _buf (leading underscore silences warnings) _ _buf _buf

Two extra rules save 90% of beginner surprises: parentheses on function calls are optional (so set :tab_width, 2 and set(:tab_width, 2) are identical), and the last expression in a block is its return value (no return keyword needed).

2. The six primitives in ~/.config/minga/config.exs

Press SPC f p to open (or auto-create) ~/.config/minga/config.exs, edit it, and press SPC h r to reload options, keybindings, hooks, and advice live without restarting. Invalid option names or types surface a clear error instead of failing silently.

  • set Typed editor options. Example: set :theme, :catppuccin_frappe (Minga's default theme is Catppuccin Frappé), set :line_numbers, :hybrid, or set :editing_model, :cua.
  • for_filetype Per-language option overrides. Pass the filetype atom and keyword pairs: for_filetype :go, tab_width: 4, indent_with: :tabs.
  • bind & command Custom commands and keybindings. Define an Elixir block with command :name, "Description" do ... end and bind it in a mode scope with bind :normal, "SPC m t", :name, "Description".
  • on Asynchronous lifecycle hooks. Save hooks (on :after_save, fn _buf, path -> ... end) run in isolated Erlang VM processes so slow CLI formatters like gofmt or prettier never stall typing.
  • advise Emacs-style command wrappers. Wrap any built-in command with :before, :after, :around, or :override; exceptions are contained so a bug in your wrapper never crashes the editor.
  • extension Supervised packages from Hex, Git, or local paths. Declare extension :minga_git_extended, hex: "minga_git_extended", version: "~> 0.1" and optionally tune load_policy (:eager, :deferred, or {:on_command, [...]}).

3. Interactive config.exs Builder

Choose your preferences and optional guardrails below to assemble a valid, copy-ready ~/.config/minga/config.exs file. Every option emitted here ships on main today:

INTERACTIVE BUILDER · ~/.CONFIG/MINGA/CONFIG.EXS Reload live with SPC h r
Include starter snippets
~/.config/minga/config.exs 
use Minga.Config

set :theme, :catppuccin_frappe
set :line_numbers, :hybrid
set :tab_width, 2

for_filetype :go, tab_width: 4, indent_with: :tabs

on :after_save, fn _buf, path ->
  if String.ends_with?(path, ".go") do
    System.cmd("gofmt", ["-w", path])
  end
end

extension :minga_git_extended,
  hex: "minga_git_extended",
  version: "~> 0.1",
  load_policy: {:on_command, [:git_log]}

4. When to graduate from config.exs to a package

Stay in config.exs for personal options, keybindings, save hooks, MCP server definitions, and short commands. Graduate to a supervised minga_sdk package when you want your own OTP supervision tree, custom buffer surfaces, an internal MingaAgent.InferenceRoute proxy, runtime tree-sitter grammars, or a package you share across teammates via Hex or Git. Compiled extension updates activate cleanly on restart (ADR-0003) rather than splitting module versions mid-session.

For one-off tasks like auditing a migration or annotating a design spec, v0.1.0 adds a middle layer: disposable and reusable Elixir workflows authored over real buffer and agent owners, reviewed as a diff, activated under an explicit revocable grant, and discarded when the PR lands or saved for reuse across repos.

Read Extending Minga for a complete minga_sdk module example and security boundaries, or browse the Configuration Reference.
