Getting Started

Install Minga alongside your current editor with zero repo lock-in, pick Vim or standard desktop shortcuts, connect a model, and review your first staged agent edit.

1. Install 2. Zero-config defaults & keys 3. Connect a model 4. Your first staged edit

1. Install Minga

On Apple Silicon macOS, Homebrew installs signed, notarized rolling prereleases. The desktop app (minga-mac) and terminal client (minga) are independent; install whichever you want, or both.

Apple Silicon macOS · Homebrew
# Desktop app only
brew install --cask jsmestad/minga/minga-mac
open -a Minga

# Terminal client only (or install both)
brew install jsmestad/minga/minga
minga path/to/project
From source · Linux & Intel macOS
git clone https://github.com/jsmestad/minga.git
cd minga
mise install          # or: asdf install
mix deps.get
mix compile && make native.support
bin/minga             # builds and starts terminal client

Building from source requires the toolchains pinned in .tool-versions (Erlang, Elixir, Go, and Zig; prefer mise or prebuilt OTP packages to avoid compiling Erlang from scratch). Building the macOS desktop app from source (bin/minga-mac) additionally requires Xcode and xcodegen. The first build takes several minutes while syntax grammars compile; incremental rebuilds after that are fast. Update Homebrew installs with brew upgrade minga or brew upgrade --cask minga-mac.

2. Zero-config defaults and core keys

You can try Minga side by side on any existing Git repository with no configuration file:

  • Zero repository footprint: Minga never drops hidden config folders or proprietary files into your project.
  • Language servers auto-attach: Any LSP binary already on your $PATH (such as gopls, rust-analyzer, typescript-language-server, or expert) attaches automatically by filetype and project root.
  • Existing API keys work automatically: Environment variables like ANTHROPIC_API_KEY and OPENAI_API_KEY are picked up immediately without re-entering them.

Vim modal or standard desktop shortcuts

Minga defaults to Vim modal editing, where pressing Spacebar (written SPC) in Normal mode opens an interactive command menu that narrows as you type (f for files, b for buffers, s for search, a for agent). Prefer standard desktop shortcuts (Cmd+C/Cmd+V/Cmd+S, arrows, no modes)? Open your config file with SPC f p and add one line:

~/.config/minga/config.exs 
use Minga.Config

# Switch to standard desktop shortcuts (CUA) instead of Vim modes
set :editing_model, :cua

set :theme, :catppuccin_mocha
set :tab_width, 2

In Vim mode on today's prerelease build, these shortcuts cover most of your first session:

  • SPC Open the command menu. Shows every mnemonic group so you do not need to memorize shortcuts up front.
  • SPC f f / SPC s p Find a file or search across the project. Save with SPC f s (or :w), quit with SPC q q (or :q).
  • SPC a a Switch to or from the Agent view on today's build (SPC a t is an alias; see the Spine migration note below).
  • SPC a p / SPC a P Publish or discard staged agent edits once a turn finishes.
  • SPC f p / SPC h r Open and reload ~/.config/minga/config.exs (creates a starter file on first open; reloads options, bindings, hooks, and command wrappers in place).
Migrating toward the Spine (ADR-0006)

The shortcuts above match today's rolling Homebrew build. As the ADR-0006 Spine design lands surface by surface toward v0.1.0: SPC a a moves to the *minga-tasks* drawer while SPC a v opens the conversation split, SPC a r opens *minga-review*, SPC g k / SPC g r keep or reject changes inline in any file, SPC 1 through SPC 4 jump to pinned files (replacing tabs), SPC o t toggles the built-in terminal drawer, holding ⌘ on macOS reveals visible shortcuts, and :checkhealth terminal reports detected terminal features. See the full table in docs/design/keys.md.

3. Connect a model provider

Minga runs its own built-in agent loop across Anthropic, OpenAI, OpenAI Codex, Google, OpenRouter, Groq, Mistral, and DeepSeek, plus custom internal gateways added through extensions.

  1. 01

    Use an existing env var or run /model

    If ANTHROPIC_API_KEY, OPENAI_API_KEY, or another provider key is already exported in your shell environment, Minga detects it automatically. Otherwise, open the Agent view (SPC a a on today's build, SPC a v under the Spine) and run /model.

  2. 02

    Save a key through the masked prompt

    Pick a provider's API-key action (or run /auth anthropic) and enter your key in the masked prompt, never in the chat box. Keys are saved locally in ~/.config/minga/credentials.json with 0600 permissions, never logged, and never exported in session history.

  3. 03

    Choose a model and start working

    Run /model again to pick your model. Useful slash commands: /thinking high for extended reasoning, /tasks for the conversation checklist, /clear for a fresh session, and /help for the full list.

For switching models mid-session and credential precedence rules, see Agent Model Selection in the Reference docs.

4. Walk through your first staged edit

Approved agent edits do not touch your open buffers or working tree until you publish them. Every tool approval uses the same keys everywhere Minga asks: y once, a always for this session, t this turn, n deny.

  1. 01

    Prompt the agent on a file in your repo

    Ask the agent to make a change and approve its file edit tool call. Your open buffer and working tree stay unchanged while the edit stages in an isolated overlay.

  2. 02

    Review staged hunks or edit your buffer directly

    On today's build, click Review on any changed file in the Agent view to open the read-only diff viewer. In Vim Normal mode with the viewer focused, jump between hunks with ]c / [c, accept a hunk with y (or all with Y), or reject with x (or all with X). Need to edit directly or send more context? Switch to your open file buffer, edit with full LSP and undo intact, and press SPC a b (current unsaved buffer, up to 32 KiB) or SPC a D (published local file diagnostics) to attach it to an open draft. Under the ADR-0006 Spine migration, review also moves directly into files via the Twist gutter (SPC g k/r, ih/ah, per-author undo) alongside *minga-review* (y/n/=).

  3. 03

    Publish with three-way merge

    Press SPC a p (or click Publish in the turn-end notice) to merge staged edits into open buffers and disk with undo intact, or SPC a P to discard them. If you edited overlapping lines yourself, Review opens conflict resolution (x for Keep mine, y for Use Agent version) instead of overwriting either change.
