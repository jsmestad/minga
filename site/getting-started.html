Getting Started

Install Minga, learn the six keys that open the rest of the workbench, connect a model provider, and walk through your first staged diff review.

1. Install 2. Six core keys 3. Connect a model 4. First staged edit 5. Starter config

1. Install Minga

On Apple Silicon macOS, Homebrew installs both the native Swift + Metal app (Minga.app) and the Go terminal client (minga). On Linux, Intel Macs, or when developing Minga itself, build from source using the pinned toolchains in .tool-versions (Erlang, Elixir, Go, and Zig).

macOS · Homebrew 
brew install --cask jsmestad/minga/minga-mac
brew install jsmestad/minga/minga

# Launch GUI or terminal client
open -a Minga
minga path/to/project
From source · macOS & Linux 
git clone https://github.com/jsmestad/minga.git
cd minga
asdf install && mix deps.get
mix compile && make native.support

# Launch terminal client or macOS GUI
bin/minga
bin/minga-mac

The first source build takes a few minutes while Zig compiles 50 tree-sitter grammars; incremental rebuilds after that are fast. Both asdf and mise read .tool-versions directly. Update rolling Homebrew builds anytime with brew upgrade minga or brew upgrade --cask minga-mac.

2. The six keys that open the rest of the workbench

Minga supports both Vim modal editing and standard CUA desktop shortcuts. In Normal mode, pressing SPC opens a Which-Key popup grouped by mnemonic prefix (f for files, b for buffers, s for search, a for agent), so you can discover commands on demand instead of memorizing a cheat sheet up front.

  • SPC Open the command menu. Read the Which-Key popup and press the next mnemonic letter to narrow down.
  • SPC f f / SPC s p Find files or search the project. Project roots are detected automatically and shared with LSP clients.
  • SPC a a / SPC a t Toggle the agent panel or full agent workspace. Keep your editor buffers open beside the conversation.
  • ]c / [c · y / x Review staged agent diffs inline. Jump across hunks with ]c/[c, accept with y, reject with x.
  • SPC a p / SPC a P Publish or discard staged agent edits. Publish runs a three-way merge into open buffers and disk; discard drops staged changes cleanly.
  • SPC f p / SPC h r Open and reload your config. Opens ~/.config/minga/config.exs (creating a starter file if missing) and reloads options, bindings, hooks, and advice in place.

3. Connect a model provider

Minga ships a native multi-provider runtime covering Anthropic, OpenAI, OpenAI Codex, Google, OpenRouter, Groq, Mistral, DeepSeek, plus custom routes added by extensions. Credentials stay out of your chat history.

  1. 01

    Open Models and connections

    Open the agent view (SPC a a or SPC a t) and run /model in the composer.

  2. 02

    Enter credentials in the masked prompt

    Pick a provider's API-key action (or run /auth anthropic) and enter the key in that masked prompt, never in the chat composer. Submitting saves the credential locally without sending your draft.

  3. 03

    Select an exact model route

    Run /model again and choose a model for your connected provider. Saved sessions remember the selected route identity, never the key. Use /thinking high for extended reasoning, /tasks for the session checklist, or /help to see all slash commands.

For route selection rules, credential profiles, and native replay compatibility across providers, see Agent Model Selection in ExDoc.

4. Run your first staged edit

Unlike terminal harnesses that write straight to disk while you hope nothing collides, Minga stages approved agent edits inside an isolated in-memory overlay until you decide to land them:

  1. 01

    Ask for a real change on an open file

    Open a file in your project, prompt the agent, and approve its edit tool call. Notice that disk and your open buffer still show the original text while the turn finishes.

  2. 02

    Inspect hunks and steer directly

    Choose Review on the changed file to walk hunks (]c / [c) with full tree-sitter highlighting and live LSP diagnostics. Accept good hunks (y), reject anything wrong (x), or hand-edit directly in the buffer. Need another pass? Attach your live unsaved buffer (SPC a b) or published file diagnostics (SPC a D) straight to the agent draft.

  3. 03

    Publish with three-way merge

    Press SPC a p (or click Publish in the turn-end notice) to merge staged edits into open buffers and disk with undo intact, or SPC a P to discard them. If you edited overlapping lines in the meantime, Review shows both sides (Keep mine / Use Agent version) instead of clobbering either edit.

Read Architecture: Buffer-Aware Agents for the visual diagram of how forks, revisions, and crash-safe staged drafts work.

5. Make it yours in five lines

Press SPC f p to open ~/.config/minga/config.exs (respects $XDG_CONFIG_HOME). You do not need to know Elixir to configure basics; set :option, value covers options, and SPC h r reloads changes in place:

~/.config/minga/config.exs 
use Minga.Config

set :theme, :catppuccin_mocha
set :line_numbers, :relative
set :tab_width, 2
set :format_on_save, true
