Getting Started

Install Minga alongside your current editor with zero repo lock-in, connect a model provider, review your first staged edit, and drop starter recipes into config.exs.

1. Install 2. Defaults & keys 3. Connect a model 4. First staged edit 5. Starter recipes

Tailored path: brew install --cask jsmestad/minga/minga-mac && open -a Minga · Vim modal defaults are active out of the box.

1. Install Minga

Signed rolling packages bundle their own Erlang runtime and update through your native package manager: Homebrew on Apple Silicon macOS, and packages.mingacode.dev on Arch & Omarchy, Ubuntu 24.04+, Debian 13+, and Fedora (x86_64/ARM64, glibc 2.39+; signing key 2C5D 2396 B82C 1278 D459 6A09 6571 1C0C 3853 857B).

Apple Silicon macOS · Homebrew
# Desktop app (Minga.app)
brew install --cask jsmestad/minga/minga-mac
open -a Minga

# Terminal client (or install both)
brew install jsmestad/minga/minga
minga path/to/project
Arch Linux & Omarchy · pacman
# Trust signing key, register [minga] repo, and install on Arch / Omarchy
curl -fsSL https://packages.mingacode.dev/minga.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key 2C5D2396B82C1278D4596A0965711C0C3853857B
curl -fsSL https://packages.mingacode.dev/arch/minga.conf | sudo tee -a /etc/pacman.conf > /dev/null
sudo pacman -Syu minga
Ubuntu 24.04+ & Debian 13+ · apt
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://packages.mingacode.dev/minga.asc | sudo tee /etc/apt/keyrings/minga.asc > /dev/null
curl -fsSL https://packages.mingacode.dev/apt/minga.sources | sudo tee /etc/apt/sources.list.d/minga.sources > /dev/null
sudo apt update && sudo apt install minga
Fedora · dnf
sudo curl -fsSLo /etc/yum.repos.d/minga.repo https://packages.mingacode.dev/rpm/minga.repo
sudo dnf install minga
From source · older Linux & Intel macOS
git clone https://github.com/jsmestad/minga.git
cd minga
mise install          # or: asdf install
mix deps.get
mix compile && make native.support
bin/minga             # builds and starts terminal client
One-off .deb / .rpm downloads, source prerequisites & upgrades

Prefer trying Linux without adding a repository? Download a standalone .deb or .rpm from GitHub Releases and install it with sudo apt install ./minga_*.deb or sudo dnf install ./minga-*.rpm. Source builds use the toolchains pinned in .tool-versions (Erlang, Elixir, Go, Zig; prefer mise); bin/minga-mac also requires Xcode. Upgrade Homebrew with brew upgrade minga or brew upgrade --cask minga-mac; Linux repo installs update with your normal system upgrades.

Launch commands, Finder & the Fedora key prompt

In a terminal, minga opens an empty buffer, minga path/to/file opens a file, and minga lib/ test/ opens several files or directories at once. From a source checkout, run bin/minga with the same arguments, or bin/minga-mac for the macOS app.

On macOS, Minga appears under Open With in Finder for any file, including dotfiles and scripts without an extension. To make it the default editor for a kind of file, select one in Finder, choose File → Get Info, pick Minga under Open with, and click Change All….

On Fedora, dnf asks you to confirm the signing key on first install. Check that it shows the fingerprint above before you accept.

Shortcuts below match current prerelease builds; upcoming v0.1.0 bindings are noted inline and interactive in Lesson 02.

2. Zero-config defaults and core keys

Open any Git repo with zero config: zero files written to your repo, LSP binaries on $PATH attach automatically, shell API keys work immediately, and Catppuccin Frappé is the default theme.

Vim modal default (with optional CUA shortcuts)

With Vim keys you are in one of two core modes. Normal mode moves and runs commands: h j k l move, dd deletes a line, / searches. Insert mode types text: press i to enter it and Esc to leave.

Press Spacebar (SPC) in Normal mode for a searchable command menu. These five bindings cover your first session:

  • SPC Command menu. Shows every mnemonic group (f files, b buffers, s search, a agent).
  • SPC f f / SPC s p Find a file or search project. Switch between open buffers with SPC b b, save with SPC f s or :w, quit with SPC q q or :q.
  • SPC a a Toggle Agent view. Opens tasks drawer (SPC a v opens conversation).
  • SPC a p Publish or discard staged edits in one Publish edits… prompt, or click Publish or Discard on the turn-end notice.
  • SPC f p / SPC h r Open and live-reload ~/.config/minga/config.exs in place.
Prefer standard desktop shortcuts (CUA)?

Add one line to ~/.config/minga/config.exs (CUA diff review uses Alt+Down/Up to step hunks, Cmd/Ctrl+Enter to accept, and Cmd/Ctrl+Backspace to reject):

~/.config/minga/config.exs 
use Minga.Config

set :editing_model, :cua
set :theme, :catppuccin_frappe
set :tab_width, 2

3. Connect a model provider

Built-in multi-provider loop for Anthropic, OpenAI, Google, OpenRouter, Groq, Mistral, DeepSeek, plus custom proxies.

  1. 01

    Use an env var or run /model

    Exported shell keys (ANTHROPIC_API_KEY, OPENAI_API_KEY, etc.) attach automatically; otherwise open Agent (SPC a a) and run /model.

  2. 02

    Save a key via masked prompt

    Run /auth anthropic (never paste keys in chat). Saved locally in ~/.config/minga/credentials.json (0600), never logged or exported.

  3. 03

    Pick a model and start

    Run /model to pick your model (Model Selection), then type a prompt and press Enter.

Useful slash commands

  • /model <name> Switch models in the middle of a conversation.
  • /thinking high Set the thinking level to high for harder problems.
  • /tasks Inspect the checklist for this conversation.
  • /clear Start a fresh session.
  • /help List every slash command.

4. Walk through your first staged edit

Approved edits stage off disk until publish. Tool approvals share one key set: y once, a session, t turn, n deny.

  1. 01

    Prompt on any repo file

    Ask the agent to edit a file and approve the tool call; your open buffer and working tree stay untouched.

  2. 02

    Review staged hunks or attach buffer context

    Click Review for syntax-highlighted hunks (]c/[c step, y/Y accept, x/X reject). To edit directly or attach context, switch to your open buffer and press SPC a x b (buffer snapshot) or SPC a x d (diagnostics); the rest of the context keys live under SPC a x.

    *minga-review* moves hunks to ]h/[h, y keep, n reject.

  3. 03

    Publish with three-way merge

    Press SPC a p and pick Publish to merge into open buffers and disk with undo intact, or pick Discard. Overlapping edits open conflict resolution (x keep mine, y agent version).

5. Four starter recipes

Drop any of these directly into ~/.config/minga/config.exs (reload live with SPC h r) or run remote agents over SSH:

PreToolUse veto hook (~/.config/minga/config.exs)
# Run a local script before any shell tool call; non-zero exit blocks the tool.
set :agent_hooks, [
  %{
    event: "PreToolUse",
    tool: "shell",
    command: "~/.config/minga/hooks/check-shell-command.sh",
    timeout_ms: 10_000
  }
]
Crash-isolated stdio MCP server (~/.config/minga/config.exs)
# Attach stdio MCP servers; if one crashes, built-in tools and other servers keep running.
set :agent_mcp_servers, [
  %{
    name: "github",
    command: "npx",
    args: ["-y", "@modelcontextprotocol/server-github"],
    env: %{"GITHUB_PERSONAL_ACCESS_TOKEN" => System.fetch_env!("GITHUB_TOKEN")}
  }
]
Lazy extension load_policy (~/.config/minga/config.exs)
# Install from Hex and defer child process startup until a command is invoked.
extension :minga_git_extended,
  hex: "minga_git_extended",
  version: "~> 0.1",
  load_policy: {:on_command, [:git_log]}
Remote headless devbox
# On your Linux devbox (stays alive across laptop sleep via systemd linger)
minga --headless

# From macOS or another terminal (zero source copy)
minga attach ssh://devbox/work/app
