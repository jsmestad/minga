What renders what

Drawer a Lip Gloss layer floating over the dimmed editor (lipgloss.NewLayer + Canvas, already used in go/tui), inset past the line numbers, with a soft drop shadow: dim ▌ on the right edge, ▀ under the bottom. RoundedBorder() takes the focus colour only while focused. Body on Surface.
Header in the border buffer name dim, title bold, state counts right-aligned in the top border. Key help in the bottom border (help.Model short view). No extra hint line above the modeline.
Rows bubbles/list with a custom delegate: glyph, goal, state words in the state colour, one action, age. Hairline separators in SurfaceAlt.
Selection a full-width Background bar plus a left ▌ in the row's state colour. The needs-you row expands in place to show the request and its four answers.
Links file paths are OSC 8 hyperlinks (Lip Gloss v2 Hyperlink): a faint underline, clickable in the terminal, opening the file in Minga.
Working ◐ is a bubbles/spinner with Frames: ◐ ◓ ◑ ◒, 8 fps, static when motion is reduced.
Dimmed editor foreground faded while focus is in the drawer, so the eye goes to the drawer. Restored on q.
One key, one meaning r only retries, o shows output, ↩ opens.
