Board note: keys
⌃\ ⌃N leaves TERM for NORMAL; i goes back. Esc and ⌃C always reach the shell in TERM. In NORMAL: ]] [[ commands, yic copy output, yac copy block, ↩ on a failed block opens its menu. *minga-shell* has no TERM mode: you watch, scroll and interrupt, you never type into Minga's shell.
Board note: how Lip Gloss draws it
Drawer: lipgloss.RoundedBorder() with the title set into the top border and the key help in the bottom border, so no extra hint line sits above the modeline.
Surfaces: drawer background one step darker than the editor; a failed block gets a faint red row tint, a pending one a faint amber tint.
Blocks: separated by a dim rule, not blank lines. Gutter: state glyph (◐ ● ◆ ◉), then authorship: │ yours, and for Minga's a two-tone cell: ▐ light over shade on each line, ▚ on the first line so the strands cross.
Links: file:line in test and shell output is an OSC 8 hyperlink (Lip Gloss v2 Hyperlink); click opens the file at the line.
Running: the ◐ is a bubbles/spinner with frames ◐ ◓ ◑ ◒.
Modeline: segments are background blocks, not text separated by pipes; the mode pill is the only saturated block.
Menu: a bordered overlay with a full-width selection bar, the same component as completion.
