Launched from a shell
minga ~/code/minga zsh
~ ❯ minga
Minga takes over the terminal. On quit it prints
Ciao. and you are back at this prompt.
Outside any project, home lists recent projects instead of files. A project with Minga still working shows it, so you can go straight back. Opening a project restores its session if it has one.
