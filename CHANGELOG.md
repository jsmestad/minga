# Changelog

All notable changes to Minga are documented here through reviewed pull requests. Candidate preparation and verification do not edit this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## Unreleased

### Added

- `/model` can select Apple Intelligence without credentials on eligible macOS 27+ devices in builds that include the inference helper. It runs on device with a compact file tool set and keeps normal approvals.
- `SPC h a` searches command names and descriptions and opens the selected command's help without running it.
- Agent workspaces have a **Tasks** inspector. The checklist, blockers, and retained results survive restart and follow the selected conversation branch.
- `SPC a F` attaches saved text from a selected project file to a local Agent draft. The attachment retains what was read, even if the file changes before sending.
- `SPC a D` or the macOS editor context menu captures a file's published diagnostics as an inspectable Agent draft attachment.
- The Agent can pause for a question. Use **Answer question** or `SPC a Q` to choose an answer, type your own, or cancel without granting tool permission.
- Successful rolling builds from `main` publish Apple Silicon packages to the Minga Homebrew tap. Use `brew upgrade minga` for the TUI or `brew upgrade --cask minga-mac` for the GUI.

### Changed

- Elixir builds use checked-in protocol and language-alias sources. Run `mix codegen` to refresh them after schema changes; CI rejects drift.
- Standalone TUI downloads are native Mix release archives instead of self-extracting binaries. Linux builds target Ubuntu 24.04 glibc; the macOS DMG build is unchanged.
- Generated Python bytecode is excluded from version control while local script caches remain untouched.
- Models and connections opens a separate masked API key prompt from the Agent workspace. Saving or canceling does not send or replace the draft. `/auth <provider>` opens the same prompt and no longer accepts a key on the command line.
- Local ChatGPT sign-in is available from Models and connections and `/login`. Cancel stops the current authorization attempt without changing credentials or the draft. The manual fallback uses masked input.
- On macOS, pickers open below the window toolbar so the search field and results do not overlap the window controls. The selected row uses readable text on the selection background.
- On narrow terminals, status notices stay readable when optional file and cursor information does not fit.
- Native approval geometry checks bind the live host and window to their run before making one foreground request. Acceptance still requires external foreground observation, global button hits, native captures and complete child cleanup.
- macOS Agent elapsed-time refreshes stop when the context bar disappears and refresh immediately when a new dispatch timestamp arrives.
- Idle Agent activity no longer appears as completed work while unfinished tasks or retained activity remain visible.
- Agent transcript updates locate streaming tails and tool calls through indexed source storage. Atomic revision cursors return only current changed entries, with consistent identity, pins, usage and reset facts instead of separate full-history queries.
- Session storage can preserve a bounded draft separately from the model conversation, even before the first turn. Draft revisions reject stale saves and protect retained attachments. This does not enable composer autosave.
- Agent History on macOS and in the terminal opens older retained messages without moving the live transcript or changing the draft. Use History or `SPC a H`, then select Earlier retained messages to page back. Select a message to copy its retained text.
- The Go TUI preserves every step in a finite wheel burst, including direction changes and source-bound composer scrolling, without waiting for another input event. Pointer-motion throttling, modifiers and surface routing are unchanged.
- Long styled Agent transcript text no longer drops the workspace frame. Both frontends receive the complete text and styling without changing retained message content.
- Terminal Agent transcripts apply validated frame changes to paged resident storage without cloning or reindexing retained history. Stable message occurrences and reading anchors survive updates, and rejected frames preserve the last-good transcript.
- Open retained tool output from macOS and Go Agent cards. Copy the original capture or a selected byte page without rerunning the tool or losing the composer draft. Partial captures are labeled.
- Long styled Agent replies wrap in the Go terminal transcript. Scroll to read the full paragraph without losing the draft. Code lines retain their existing clipping behavior.
- Background Agent writes preserve the selected Review and retained draft. Selected-file updates freeze the last-good review as stale until explicit refresh; unrelated paths do not replace it. Changed files stay in a fixed timeline without moving the composer or footer controls. Back resumes draft input, and shared source-bound Refresh and independent Help remain available in both frontends. Read-only Review wrapping preserves boundary characters beside scrollbar indicators, and narrow terminal file labels keep the filename visible.
- Composer keys now reach the active editing model against the retained prompt. Canonical and native arrow encodings no longer insert private-use key glyphs, shifted Unicode text remains intact, and Normal-mode Tab can reach retained Review while the draft stays focused.
- Release preparation produces the complete five-build candidate as immutable GitHub Actions artifacts, with final-byte checksums, provenance and a separate read-only verification rehearsal. It does not create a tag or GitHub Release, update the Homebrew tap, or push changelog changes to main.
- Go renderer changes can now be checked against actual emitted PTY bytes at narrow, default and wide terminal sizes, using canonical committed agent-workspace frames, bounded raw streams, cell grids and build metadata. The capture decoder preserves terminal scroll regions instead of reporting stale rows after composer resizing. This is separate from model-only tests and legacy Zig snapshots.
- Native conversations now freeze interned instruction/schema epochs and require an explicit fresh-conversation transition when retained replay identity changes or is unknown. Legacy continuation values remain exact, and authentication material is bound once per dispatch without persisting secrets.
- Tool effects now cross current Session policy and serialized Registry registration gates after approval and hooks, with one-shot starts, versioned option fences, durable refusals, and distinct storage failures. Removed automatic memory injection, default memory-write/introspection tools and model-cycling commands, and child backend selection; existing files, optional read/discovery packs, and registered provider owners remain intact.
- Reconciled ADR-0004 and terminal guidance with the approved full programmable v0.1.0 direction: shared definitions, independent instance upgrades and maintained Swift/Go clients. This is documentation reconciliation, not shipped live authoring.
- Native tool continuations keep retained-output references and recovery bookkeeping out of transient provider metadata while preserving durable history and provider-owned continuation data. Contract tests inspect actual encoded next requests, signed thinking, supported opaque blocks, and grouped tool-call IDs.
- Stale-intent investigation tooling can capture real native editor sessions with build provenance, dedicated debug logs, canonical-log correlation, and per-surface rejection counts. Synthetic smoke captures and incomplete evidence do not count toward the real-session cohort.
- Semantic GUI activations now retain a typed target through decoding, resolution, and application. EX9015 rejects active-subject reads in targeted clauses and index-only GUI decoders, with reasoned exemptions for existing narrow workspace and window identities.
- macOS chrome now uses shared spacing, typography, and radius scales, including a 6pt compact step and one monospaced small candidate/key style. A balanced-argument source guard rejects new literal decisions outside editor geometry. The preview command can capture every registered view, and CI attaches real before/after contact sheets with an exact pixel-change manifest for review.
- `make done` now runs the local pre-review gates in one command: fast lint, the non-heavy ExUnit suite, and the macOS build and `MingaTests` bundle when macOS inputs changed. Lint and changed-file Credo share the same change detector. Swift skips report their reason; test failures name failed tests and retain the xcresult bundle and logs.
- Native agents now use the upstream ReqLLM 1.29 release instead of a pinned fork, bringing Codex reasoning-continuation fixes, preserved streamed JSON text and thinking, and transport security fixes. Updated compatible Hex dependencies, including Req 0.7.5, Bandit 1.14.1, Exqlite 0.43.0, Hammox 1.0, and the October LLM model catalog.
- Updated ReqLLM to 1.31 with the November model catalog and refreshed the terminal renderer's Go dependencies. Release builds now use Go 1.26.11 and OpenSSL 3.5.9. Plug 1.20.4, IDNA 8.0.0, and Bubble Tea 2.1.2 include upstream security fixes.
- Agent guides now use verified paths and module entry points, list all fourteen custom Credo checks with unique IDs, and link focused development recipes. Regression tests keep guide references and the check inventory synchronized with the repository.
- Production parser and hook-runner binaries now use Zig `ReleaseSafe`, with Zig's build cache selecting the correct optimization mode. Parser queries compile only for languages in use instead of prewarming every bundled language. Editor launchers retain ERTS's specialized memory allocators instead of disabling them.
- Removed one-off benchmark scripts and archived measurement artifacts. CI performance gates and maintained documentation remain.
- LSP, diagnostic, and caret position conversion now walks UTF-8 text directly instead of building charlists or re-encoding each character, and UTF-32 position lookup runs in constant stack. Converted positions, clamping, and exact-column errors are unchanged.
- GUI search indexes now build in one linear pass when indexing into an empty tree, so initial builds and edits that remove every match no longer insert each match-bearing line persistently. Match order, counts, navigation, and incremental edits are unchanged.
- Characterwise range deletion and replacement reuse their already resolved selections, avoiding a second normalization and coordinate lookup while preserving deleted and replacement bytes, cursor placement, and edit deltas.
- Window source maps for unchanged, undecorated lines without expanded tabs now skip the composition pipeline and count UTF-16 once. Decorated lines measure source display width at most once and query conceals and inline virtual text once.
- Diagnostic decoration updates group consecutive endpoint-line reads, convert positions outside the buffer process, and share severity styles. Highlight ranges, ordering, unrelated decoration groups, and the existing read/install behavior are preserved.
- LSP change flushes share the first successful full-content snapshot across full-sync clients instead of flattening the document once per client. UTF-8 incremental clients with available deltas keep their range-only path, and failed reads still retry for later clients.
- macOS editor command preparation reuses unscrolled rows that fit the viewport instead of rebuilding their text and highlight spans. Clipped, scrolled, and out-of-range-span rows keep the existing normalization.
- macOS selection overlays index accessibility ranges once per pane and frame instead of rescanning every range for each visible row. Selection quad geometry, ordering, clipping and colors are unchanged.
- Full-content undo commits now find the changed byte range with native binary prefix and suffix comparison over bounded 4 KiB chunks instead of a per-byte Elixir scan, without copying either whole document. Patch contents, apply/invert behavior, and cursor restoration are unchanged.
- Opening or reloading a buffer in which no line starts with a merge conflict marker no longer splits every line or copies the document to build the conflict index. On a 60,000-line, 3.9 MB ASCII document, building the index drops from about 8 ms to 0.3 ms (median) wherever the edit gap sits. Documents with any marker line, including orphan markers, are indexed as before.
- Placing the cursor, including vertical moves and jumps, no longer flushes a pending line-index shift or copies the target line separately from the document. The caret clamp reads only through the requested code point, and placement uses at most one content copy. Controlled 60,000-line probes measured one-line moves with a pending shift at about 0.5–0.7 ms before and under 0.1 ms after (median), with no increase in retained binary memory. Clean regular-line and long-single-line controls remained within measurement variation. Line and column clamping, grapheme boundaries, CRLF handling, and index contents are unchanged. Clearing an already-empty line at the cursor after an edit round-trip is now a no-op even with a pending index, rather than recording a zero-width edit.
- Buffer file opens, byte-range replacements, and undo reconstruction now validate UTF-8 through the VM's native Unicode converter instead of `String.valid?/1`. Accepted and rejected input is unchanged; validating multi-megabyte files is roughly four to five times faster.
- Empty LSP semantic-token responses now check only the buffer revision instead of copying, splitting, and indexing the whole document before storing an empty layer. On 60,000-line documents of 3.5 to 7.8 MB, accepting an empty response drops from about 17 ms to under 20 µs (median), and caller heap allocation drops from about 4.5 million words to 81. Cleared layers, stale or closed-buffer rejection, and non-empty responses are unchanged.
- Case-sensitive regex searches and substitutions whose pattern contains no regex metacharacters now use the literal byte matcher instead of compiling a regex. Matches, overlaps, replacements, and invalid-regex fallback are unchanged.
- Classic forward and backward search walk document lines in order instead of repeatedly indexing them. Live substitute previews accumulate replacement positions without rescanning earlier matches. Search wraparound and byte offsets are unchanged.
- Ordinary editor startup defers agent model discovery until agent use and starts the bundled BEAM before native font and Metal setup. Unresolved models retain truthful readiness, and exact hosted route startup preserves the selected reasoning policy.
- Agent model selection now supports named hosted providers only. Ollama, anonymous routes, custom endpoints, endpoint overrides, local availability probes, and their configuration options have been removed. Unsupported routes fail without provider fallback or network probing.
- Agent tool advice now carries tool results through an explicit tagged invocation outcome. Tool-specific around callbacks must return `{:returned, state, result}` or `{:skipped, state}`; editor command advice keeps its existing state-to-state contract.
- New Agent requests no longer offer the hidden notebook tools. Existing todo tools and saved conversation history remain readable.
- Native agent tool effects now require a durable provider-continuation checkpoint and single-attempt admission; interrupted admitted calls recover as explicit indeterminate results without replay.
- Native agent model changes now resolve an exact model, wire protocol, endpoint, credential profile, reasoning controls, limits, and capabilities before activation. The model picker and slash completion expose exact route evidence; unsupported tool, image, and thinking requests are rejected before transport; and saved sessions restore the same secret-free route identity without credential fallback. See `docs/AGENT-MODEL-SELECTION.md`.
- Native agent reads, discovery, searches, shell results, and tool results now distinguish visible truncation from bounded durable capture, support binary-safe exact record-scoped retrieval across restart, preserve source revisions and timeout prefixes, reconcile interrupted delivery outputs without replay, and explicitly refuse retention quota failures. Image reads deliver retained bytes through exact model and protocol support or return a visible limitation before full capture. Combined snapshots preserve output ownership and migrate separate model-selection and retained-output records safely.
- Attach the current file selection to a local Agent draft. Both frontends show saved snapshots before sending and let you inspect or remove them. Restart restores the snapshot with its original draft.
- Attach the current editor buffer to a local Agent draft, including unsaved edits. The draft keeps those exact bytes after the source changes or Minga restarts.
- Rename a local saved Agent session from the shared command palette or with `SPC a R`. Its name stays searchable in Sessions after restart without changing the transcript or draft.
- Archive or unarchive a local saved Agent session from **Sessions**. **Browse archived sessions** recovers it with its original draft, and archiving does not stop open work.

### Fixed

- macOS TUI release builds pass the optimization flags required by Erlang/OTP. The macOS app preserves the bundled icon font directory, and macOS and Linux packages no longer ship the Windows-only file watcher.
- macOS release signing uses the runner’s native keychain settings and explicitly selects the temporary Developer ID keychain. Builds and package smoke tests still use an isolated home directory.
- macOS release CI grants `codesign` access to the imported Developer ID key. It checks key access before signing the package and logs which file it is signing if the step stalls.
- macOS loads bundled Metal shaders when the frontend executable is launched through a symlink. Startup now shows what Minga is waiting for and offers Quit from the start. If the first editor frame is late, keep waiting or retry startup in the bundled app without opening a second editor core.
- Returning to a local Agent tab reuses its conversation when no messages or pins changed. Status and approvals still refresh from the arriving session.
- Agent tools reject arguments that violate their declared JSON Schema before constructing or invoking an executable callback, including non-SDK tools. Valid SDK input normalization and defaults remain available, and the schema validator now fails closed when a regular expression exceeds its match budget.
- Invalid `/auth` and `/login` arguments no longer enter prompt history. Minga rejects indented credential commands before sending them and keeps invalid provider names and remote sign-in callback errors out of the transcript.
- Local Agent composers autosave unsent input without adding it to conversation history. Reopen the original session or its **Unsent Agent draft** row after restart; a storage failure leaves the current input in place.
- Agent workspaces show Awaiting approval without an execution animation while a tool waits for consent. Denied, Cancelled, Expired, and Error outcomes stay distinct in native and terminal conversations, including restored sessions. Approval waits do not inflate execution durations. Stopping an admitted effect preserves retained output and disclosure state without claiming that its effects were rolled back.
- Sessions rejects a stale live row or a saved row opened from a different workspace or conversation. Reopen Sessions to choose the current target without losing the outgoing draft.
- Entering plan mode, losing a provider, resetting a conversation, and restoring another conversation retire the original approval target before its identity changes. Known non-execution carries no execution duration, and plan mode does not increase the workspace's running-work count.
- Saving or removing an agent API key replaces the credential file atomically. A failed write leaves existing keys intact, and malformed files report an error without including credential contents.
- Text prompts show clickable Submit and Cancel controls in both frontends. Enter and Escape keep their existing behavior.
- Clicking a terminal picker result chooses the item shown on that row, even when the popup is narrow or scrolled. Clicking outside the picker dismisses it without choosing a result.
- A rejected manual OAuth completion no longer consumes the original session's pending login. The original client can still finish it once.
- Wheel and trackpad scrolling now reach the last screen row of a soft-wrapped file without moving the cursor there first. Both frontends scroll locally when they have the wrapped rows in memory.
- The macOS scrollbar follows screen rows in soft-wrapped panes with retained rows. It stays visible for a long single line, and dragging can land within that line without moving the cursor.
- Repeated wheel ticks on an oversized wrapped line reuse the renderer's measured row count instead of laying out the unchanged line again on the input path.
- Soft wrap stays on when a buffer contains closed folds, virtual lines, or Inline Ask blocks. Wheel scrolling follows the rendered rows without moving the cursor.
- Horizontal trackpad and wheel input pans the targeted pane without moving the caret. Wrapped panes ignore sideways gestures, and the terminal can show the last column even when its scrollbar is visible.
- Retained shell capture reads complete output and EOF on macOS without waiting for another chunk. Closing either parent channel stops idle, pending-read and backpressured output helpers, including when unread control bytes remain. The original producer is never replayed.
- Codex login and revoke safely replace the OAuth credential file without dropping other providers. If the running instance is refreshing its credentials, login and disconnect ask the user to retry instead of racing the refresh.
- Agent edits keep private overlay ownership instead of attempting to adopt a project file's group, which could reject valid macOS edits with `:eperm`. Owner-only staging directories prevent access widening, staged scripts retain their access permissions, and final atomic publication still preserves the original file's metadata.
- Agent startup prepares the draft before its first frame. macOS composer clicks restore Agent keybindings after sidebar focus, and Follow output remains available when a turn is idle without taking space away from the transcript.
- Opening an Agent tab from a file shows the conversation and empty composer immediately, without taking keyboard focus.
- Codex models such as GPT-5.6 Luna can continue conversations instead of stopping silently after the first reply. Replay qualification checks the exact official transport and captured inputs, including a bounded path for previously unqualified records. Rejected prompts retain their drafts and report failures; pre-admission refusal no longer adds a misleading user entry.
- Agent approval cards bind decisions to their original session, model request, and tool invocation on both frontends. Stale, duplicate, and unauthorized decisions cannot resolve a newer request or widen trust. Completed or expired waits retire their approval cards and cannot later grant trust. Approval arrival preserves active drafts; keyboard decisions respect text-entry scope and modifiers. Help and model controls use semantic actions, including from file-tree focus. Go renders scrollable Help, and native transcript controls behind Help are inactive and hidden from accessibility. Help owns input until dismissed instead of editing the covered composer.
- Native approval cards keep their warning, tool name, and summary readable at narrow widths. Their complete decision controls must pass external accessibility geometry checks at narrow, compact, and wide workspace widths, with retained full-window captures rather than in-process SwiftUI proxy assumptions.
- Go Messages label and color log entries by their committed severity. Errors show `ERR` instead of `OK`, warnings show `WRN`, and informational entries show `INF`.
- The Go Agent workspace separates reported token usage from context and displays sub-cent costs without rounding them to zero.
- The macOS Agent transcript preserves positive costs down to one millionth of a dollar and does not show a zero price when the turn has no positive cost to display.
- Agent workspace switches preserve each conversation's transcript and draft, clear stale launchpad routing, and restore composer input instead of creating an Untitled buffer. Returning to the editor without an available target keeps Agent input usable.
- The macOS Add menu creates a new agent workspace with its composer instead of toggling an existing workspace.
- Agent drafts soft-wrap into a text area that grows to eight rows and then scrolls vertically. Both frontends render canonical prompt rows with source-backed caret and selection, keep Send/Stop outside the scrolling text, and submit or stop independently of Vim mode. Native text placement stays fixed across mode changes; terminal composition preserves combining marks. Hidden sidebars no longer offset terminal composer pointer targets.
- macOS assistant replies share a visible author label, theme-colored background and border across plain, styled and Markdown output instead of blending into the transcript background.
- macOS agent-workspace previews now capture readable, frozen production views at narrow and default widths, with full-window images, bounded failures and build-input receipts. A separate procedure covers real native keyboard and mouse evidence.
- Native release preparation selects a Python build published for every host, fetches Linux prerequisites from the authenticated version-locked package index, reports bounded command failures and retains isolated build logs. CI checks changed release prerequisites on all four native hosts before the aggregate gate can pass.
- Go terminal updates no longer erase the workspace header or retain trailing status text after a shorter replacement. Cursor presentation uses Bubble Tea's typed cursor metadata instead of embedding cursor-position controls in rendered cells.
- The terminal reports the editor grid below its header, so wheel scrolling can show the final row of a windowed buffer instead of leaving it under the status bar.
- The Go protocol reader skips valid length-framed unknown UI opcodes without losing later commands in the same committed frame, while still rejecting truncated payloads and unsupported required commands.
- Standalone candidate builds now qualify a pinned native OTP/ERTS source input instead of requesting unavailable Burrito runtime archives. Build receipts, source hashes and final ERTS/NIF ABI checks fail closed without a host-runtime or download fallback.
- The native streaming contract fixture supplies explicit synthetic SDK cost and checks completed usage and continuation, so its terminal-event deadline does not depend on cold pricing-catalog initialization.
- Test configuration roots are allocated exclusively across BEAM processes, so a new run cannot adopt stale artifact namespaces without their quota ledger. Missing-ledger recovery remains fail-closed.
- Opening file URLs from iTerm2, Finder, or `open -a Minga` now preserves the native editor window, preventing tabs from showing stale contents after a second file opens.
- macOS keeps workspace controls and open tabs in one fixed-height header row, including when no tabs are open. The default footer no longer repeats the workspace label. Tab reordering uses a declared native JSON drag type without competing workspace-swipe gestures.
- CI now reports fail-closed aggregate gates for every substantive job and Chrome preview evidence. Preview path detection runs on every pull request, skips captures only for unrelated changes, and always requires real captures for manual dispatches.
- Repeated release builds no longer accumulate obsolete Erlang runtimes and dependency versions. macOS and standalone TUI packages include only Minga's runtime resources, excluding test harnesses, retired renderers, and other development leftovers. Production Go renderers omit debug metadata and local build paths without removing language support or runtime extension compilation.
- Release cleanup refuses output paths outside the active Mix build directory, protecting shared installation prefixes from deletion. Custom `mix release --path` destinations must be below that build directory.
- Cursor-left and Backspace no longer scan all preceding buffer text on each action. Line-boundary lookup searches backward in bounded chunks, and grapheme lookup reads only the final line while preserving Unicode and CRLF boundaries.
- Converting between document points and editor positions no longer walks or copies buffer content. Range edits, replacements, and edit deltas resolve positions through the cached line index, including pending line shifts, while keeping exact byte columns.
- Deleting or moving the cursor across a CRLF line ending now updates the line count, cursor line, and line index. Previously the CRLF pair was treated as an ordinary character, so later positions resolved to the wrong line.
- Git tracking resolves project-directory aliases before reading HEAD, including new paths under a symlinked parent.
- Whole-file additions and deletions use direct line-diff hunks instead of a quadratic Myers workspace, preventing large transient heaps for untracked files.
- The macOS protocol reader releases temporary Foundation read buffers after each packet instead of retaining them until its background thread exits.
- Extension callback completions reuse the request snapshot when no state changed, and the effect scheduler releases its idle heap after a burst.
- Bundled extensions boot their isolated compiler and validator with the release's clean boot script and library path.
- Bounded agent command collection now terminates live producers before closing their Ports on timeout or capture exhaustion. Search and shell commands no longer continue consuming CPU after returning an incomplete result.
