# Changelog

All notable changes to Minga are documented here through reviewed pull requests. Candidate preparation and verification do not edit this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## Unreleased

### Added

- If startup stalls on macOS, choose **Restart in Safe Mode** to replace the editor core without loading user configuration or extensions.
- macOS and terminal startup show the extension name when Minga needs to compile it.
- Subscription model routes can show a setup row in `/model` that checks the route's sign-in off the editor and reports the exact command to run, show their plan usage and reset time on model rows, and refresh their model list whenever Minga checks them. Routes can declare a `short_name` such as "Claude" for these sentences. When a plan limit is reached, the chat says when it resets and, on macOS, offers a "Choose another model" action that keeps the draft.
- Extensions can add model routes with `Minga.Extension.ModelRoutes.register/2`. Their models appear in `/model` with the route's own readiness, limits, and thinking levels, and they run inside Minga's normal agent turn: tools, approvals, retries, compaction, and history stay in Minga. An unavailable or removed route never becomes the active model, and Minga never falls back to another model. Route-only settings go in `routes.<route_id>.env` in `credentials.json`. The route contract uses only Minga-owned values, so routes keep working across Minga's internal model-library changes.
- `/model` can select Apple Intelligence without credentials on eligible macOS 27+ devices in builds that include the inference helper. It runs on device with a compact file tool set and keeps normal approvals.
- `SPC h a` searches command names and descriptions and opens the selected command's help without running it.
- Agent workspaces have a **Tasks** inspector. The checklist, blockers, and retained results survive restart and follow the selected conversation branch.
- `SPC a F` attaches saved text from a selected project file to a local Agent draft. The attachment retains what was read, even if the file changes before sending.
- `SPC a D` or the macOS editor context menu captures a file's published diagnostics as an inspectable Agent draft attachment.
- The Agent can pause for a question. Use **Answer question** or `SPC a Q` to choose an answer, type your own, or cancel without granting tool permission.
- Agent chat keeps Send, Steer, Queue Next, and Stop in fixed positions on macOS and in the terminal. Steer and Queue Next act on the displayed saved conversation and appear disabled when that action is unavailable.
- Agent tabs show their conversation, a starting message, or the reason the chat is unavailable. A failed start keeps the current draft. Returning to an Agent tab restores its composer, including when the previous composer closed unexpectedly.
- Successful rolling builds from `main` publish Apple Silicon packages to the Minga Homebrew tap. Use `brew upgrade minga` for the TUI or `brew upgrade --cask minga-mac` for the GUI.

### Changed

- On macOS, Agent chat no longer copies the whole retained history into a new array each time the transcript changes. Rows are read from the stored history on demand. In an offscreen benchmark with 10,000 retained messages, the CPU for each file-change update fell by about 30%. Message identity, dividers, the draft, and scroll position are unchanged.
- Adversarial, Knowledge Graph, and Ghost Cursors are now opt-in. [Add the corresponding Git install line](docs/CONFIGURATION.md#optional-extensions) and restart to keep using them. Existing Knowledge Graph data stays in place.
- GitExtended replaces bundled Git porcelain. [Add its Git install line](docs/CONFIGURATION.md#optional-extensions) in place of `extension :git_porcelain` and restart to enable Git workflows and their `SPC g` bindings. The modeline branch, gutter signs, and file tree status work without it.
- Elixir builds use checked-in protocol and language-alias sources. Run `mix codegen` to refresh them after schema changes; CI rejects drift.
- Standalone TUI downloads are native Mix release archives instead of self-extracting binaries. Linux builds target Ubuntu 24.04 glibc; the macOS DMG build is unchanged.
- Generated Python bytecode is excluded from version control while local script caches remain untouched.
- Models and connections opens a separate masked API key prompt from the Agent workspace. Saving or canceling does not send or replace the draft. `/auth <provider>` opens the same prompt and no longer accepts a key on the command line.
- Local ChatGPT sign-in is available from Models and connections and `/login`. Cancel stops the current authorization attempt without changing credentials or the draft. The manual fallback uses masked input.
- On macOS, pickers open below the window toolbar so the search field and results do not overlap the window controls. The selected row uses readable text on the selection background.
- **All Changes** omits the directory shared by the results, so files with the same name show their distinguishing directory sooner. Search still accepts full paths.
- When the Agent and a human edit the same file region, Review shows **Keep mine (x)** and **Use Agent version (y)** for the selected conflict. A stale comparison must be reopened before applying a choice.
- On narrow terminals, status notices stay readable when optional file and cursor information does not fit.
- The traditional modeline reads only placement metadata when ordering custom segments and builds status bar output without intermediate groups.
- Native approval geometry checks bind the live host and window to their run before making one foreground request. Acceptance still requires external foreground observation, global button hits, native captures and complete child cleanup.
- macOS Agent elapsed-time refreshes stop when the context bar disappears and refresh immediately when a new dispatch timestamp arrives.
- Agent tab and workspace names use the transcript already read by the editor instead of requesting the same conversation again.
- Switching to a busy local Agent session stops waiting after 250 ms. Your draft and transcript position are retained, and live controls return automatically when the session answers.
- On macOS, typing in the Agent composer, moving the caret and opening prompt completion no longer re-evaluate the conversation, so typing costs the same in a long session as in a new one.
- Idle Agent activity no longer appears as completed work while unfinished tasks or retained activity remain visible.
- Agent activity keeps showing the remaining tool when another concurrent call finishes. Tool updates no longer read the Session to choose an active tool.
- Agent activity shows an error even when the turn fails before running a tool, changing a file, or creating a checklist item.
- A timed-out Agent hook escalates termination even if its shell exits before a descendant that ignores `TERM`.
- Agent prompt readiness uses the current session's published connection state instead of waiting on separate provider and session lookups. A starting or unavailable session keeps the draft.
- Agent shell operations terminate their process group on timeout or when the owning worker exits, preventing delayed writes by ordinary background children.
- Agent transcript updates locate streaming tails and tool calls through indexed source storage. Atomic revision cursors return only current changed entries, with consistent identity, pins, usage and reset facts instead of separate full-history queries.
- Switching Agent transcript branches keeps only relevant pins without collecting every saved message ID. Restoring transcripts scans identity candidates without flattening the snapshots or changing the allocator's existing rules.
- Session storage can preserve a bounded draft separately from the model conversation, even before the first turn. Draft revisions reject stale saves and protect retained attachments. This does not enable composer autosave.
- Agent History on macOS and in the terminal opens older retained messages without moving the live transcript or changing the draft. Use History or `SPC a H`, then select Earlier retained messages to page back. Select a message to copy its retained text.
- Agent edit attribution reads the relevant turn in one ordered pass and stops exact-line scans at the first match. It preserves match priority and excludes replies after the selected edit.
- Open **Queued Agent inputs** in the Agent header or with `SPC a J`. Edit a pending input in a multiline buffer and use the normal Save command to update it, or withdraw it from the queue. Neither action changes neighboring inputs or your current draft. If the selected revision has already changed or left the queue, Minga does not modify another item.

### Fixed

- Reject holds conflicting Agent edits rather than choosing one by order. Independent edits can still be rejected in the same press. Compacting Agent drafts preserves the user's later undo and does not restore text the user deleted.
- Typing stays responsive while the agent streams. The editor no longer waits on a busy session to update the conversation, which could hold keys for up to five seconds.
- Sending a message or stopping a turn no longer holds the editor while the session answers. The composer keeps the message until the session takes it, text typed meanwhile stays, and a second press never sends the same text twice.
- The first message of a new conversation with Apple Intelligence (On Device) is sent on the first press. It used to fail once with "could not count its fixed instructions and tools within 3 seconds" and hold the editor meanwhile. Minga now prepares the model when the conversation opens, and a message sent before that is ready shows as working and goes when it is. Stop works meanwhile, a second message queues behind the first, and if the model cannot be prepared the draft is kept and one line says to try again.
- `SPC a s` stops a working turn from any buffer. With a file in front it used to answer "That Agent turn is no longer active" while the turn kept working. With several conversations working it stops the one shown last, and says so when it cannot tell which one you mean. When it stops a conversation the modeline is not showing, the echo area names it.
- With a file in front, the modeline follows the conversation shown last. It used to keep the state that conversation had when it left the front, so it could read "Minga working" long after the turn had stopped or finished.
- The macOS agent header names the session's provider before the model, including an extension route's name such as "Claude (subscription)", as the terminal already does.
- Closing an agent workspace with its close button on macOS no longer drops its staged agent edits. The workspace stays open and offers **Publish** and **Discard** until you choose one.
- After the macOS app reconnects to a restarted editor core, it reports the window size with your configured line spacing and gutter, so the editor no longer lays out rows or columns that the window cannot show until the next resize.
- Staged agent edits survive an editor crash or restart. After the editor restarts on its own they come back to their workspace; after Minga exits without publishing or discarding them, the next start for the project restores them, says so in `*Messages*`, and offers **Publish** and **Discard** again. A file that changed on disk in the meantime is merged or kept as a conflict, never overwritten, and a saved edit that cannot be restored is reported as lost by name. The saved copies are private files that are deleted on publish or discard.
- Approved edits from an agent session started in the editor no longer vanish. They are staged until you publish them: when the turn ends, a notification offers **Publish** and **Discard** (clickable on macOS and in the terminal), `SPC a p` publishes and `SPC a P` discards, and publishing updates the file on disk and any open buffer. `:q`, `:wq`, `:qa`, `:wqa`, and quitting the macOS app stop while edits are staged; `:q!`, `:qa!` and `:cq` discard them on purpose.
- The macOS startup screen shows the Minga logo and loading phrases again. **Quit Minga** appears after ten seconds.
- CI can save a refreshed Dialyzer cache when `mix.exs` changes which applications the PLT includes, instead of repeating that repair on every run.
- Adversarial diagnostics ignore replies from superseded or invalidated analyses, so an old reply cannot restore findings after an edit, close, or clear.
- Repeated config reloads keep using the config home selected at startup.
- Source launchers keep Minga configuration and runtime data, including project switcher history, separate from the installed editor. Run `make clean` after quitting the source editor to reset the current worktree's profile without deleting build artifacts.
- macOS TUI release builds pass the optimization flags required by Erlang/OTP. The macOS app preserves the bundled icon font directory, and macOS and Linux packages no longer ship the Windows-only file watcher.
- macOS release signing uses the runner’s native keychain settings and explicitly selects the temporary Developer ID keychain. Builds and package smoke tests still use an isolated home directory.
